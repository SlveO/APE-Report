# Implementation sources

- APE official core: existing `ape/ape_llama.py`; the observed existing commit is recorded in `docs/RESULTS.md`. The T/S formula is unchanged. An optional observer receives the actual branch outputs and masses for diagnostic-only reconstruction; performance calls leave it unset.
- PCW: [AI21Labs/Parallel-Context-Windows](https://github.com/AI21Labs/Parallel-Context-Windows), Apache 2.0. `pcw_wrapper.py` defines the longest-first, unique-BOS merge and query positions. `methods.py` adapts these operations to stock Transformers 4.44.2 Llama legacy cache/GQA/Llama-3.1 RoPE; no APE function is used by PCW. Downloaded reference text and license are under `datasets/raw-main80/references/`.
- LongBench v1: [author code](https://github.com/THUDM/LongBench), MIT; dataset components retain their original licenses, recorded in the asset manifest. Official prompt text is split at `{context}` and wrapped in one common Llama user/assistant envelope; `qa_f1` follows the official English normalization and token overlap.
- Lost in the Middle: [author code/data](https://github.com/nelson-liu/lost-in-the-middle), MIT. The default `qa.prompt`, document formatting and `best_subspan_em` are preserved inside the common chat envelope. Public documents are not cropped or filled.
- Doc2Dial: [DialDoc21 author source](https://github.com/doc2dial/sharedtask-dialdoc2021), data CC BY 3.0 as stated in the author dataset card. Use the official full-document fields, tags, text2line and reversed history; retain every preceding history turn, including ungrounded turns skipped by the historical reference script. Put full document before request history to make document-only KV reusable. This template ordering adaptation is explicit in every frozen row and shared by all methods. Target only grounded agent turns, with official `{dial_id}_{preceding_turn_id}` IDs. SacreBLEU 2.4.3 uses the official corpus BLEU defaults; strict ID joins happen before library calls because SacreBLEU itself accepts unequal array lengths.

`datasets/raw-main80/ASSET_MANIFEST.json` and the assets logs record actual source URLs, fetch branches/times, formats, licenses and transformations. Mutable branches and user mirrors are labelled as such. No source file digest is computed. The old ChatQA/ChatRAG implementation is not imported or used.
