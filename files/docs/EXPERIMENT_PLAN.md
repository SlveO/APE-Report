# APE 单主线研究协议

版本：v3.0，2026-11-13。授权：`U_MAIN80`（用户要求实施完整方案）。角色、状态及写入规则见 [AGENTS.md](../AGENTS.md)，任务见[阶段文档](REPRODUCTION_STAGE.md)。

## 研究问题与固定条件

在统一模型和任务内容下建立顺序编码、PCW、默认 APE 的本机基线；研究由文档 token 长度 L 和实际编码块数 N 决定 APE T/S 的规则，在位置问答和 Doc2Dial 评价质量及效率。允许无收益或退化结果。

- 物理 GPU 0，按用户指定 RTX 4090 48GB，不审查设备/占用，不作资源预检。
- `meta-llama/Llama-3.1-8B-Instruct`，BF16，请求 batch=1，greedy、`do_sample=False`、`num_beams=1`、seed=42。
- 解释器及 TF 4.44.2 overlay 延续现有环境；先记录实际导入版本，不变更外部环境。
- 模型目标 `models/Llama-3.1-8B-Instruct`；来源 ModelScope `LLM-Research/Meta-Llama-3.1-8B-Instruct`、获取分支 `master`、safetensors、Llama 3.1 Community License 及附带使用政策。该来源为用户镜像，不是 Meta 官方发布，master 可变。记录获取时间、远端元数据、13 项必要文件；用索引、结构及离线读取验收，不计算摘要。失败保留 partial 和日志，不转用旧模型。
- 所有写入、缓存、临时文件在工作区内；共享模型及环境只读；不计算哈希或校验和。

## 准备与统一实现

先改写规则及任务卡、移除学习计划及引用，按精确清单精简日志。保留有效环境结果/锁、模型恢复来源/清单/结构/离线读取、R2 两轮真实命令/运行代码/输出/起止/退出、清理记录及简短失败说明；保护其他 dirty 变更和原版申报书。

共用数据接口、生成循环、评分、计时、保存和恢复；修复 LongBench 导入、T/S、配置路径、默认三个任务及保存。不得跳过 `length < 8000`。方法标签为 `sequential`、`pcw`、`ape_default`、`ape_fixed`、`ape_dynamic`，方法进程独立，GPU worker 严格串行。APE 调用官方三阶段及正式 T/S 接口，保留官方计算。

PCW 依据[论文作者实现](https://github.com/AI21Labs/Parallel-Context-Windows)：每窗独立因果编码、各自 BOS 起位；最长窗口置首（并列取原始首窗）保留 BOS，其他窗口剥去 BOS；问题无额外 BOS，位置接最长窗；问题/生成访问全部窗口及自身因果历史。不使用 APE 共享多 token 前缀或重标定，不能以 T=S=1 的 APE 替代。适配 Llama-3.1 的 GQA、RoPE、缓存。全部方法共用资料、问题、任务要求和停止条件；缓存/位置/token 组织差异另记。

## 数据冻结与输入

LongBench v1：Qasper、HotpotQA、MuSiQue 各 200 个有效 ID（600 题），使用[公开数据](https://huggingface.co/datasets/THUDM/LongBench)及[官方评分](https://github.com/THUDM/LongBench)。恢复原论文/支撑文档映射后分组；规范化问题相同者同组。Qasper 依论文，其他依完整支撑文档集合；分别报告证据组重合和单篇资料重合。映射缺失或歧义必须解决后冻结，不能用随机样本 ID 冒充文档组。

按数据集分层、seed=42 固定组顺序，不拆组：探索目标 17/17/16（50），验证 13/13/14（40），测试为其余约 510。保存实际数量与偏差，不用测试题补开发题。

开发集精确长度 L∈{4096,8192,16384}（问题、前缀、生成另计窗口）：保留全部必要证据及相对顺序；先支撑段落，再按距证据距离选背景，最终按原文顺序排列。不足时按固定开发池顺序补资料，排除目标证据组、含标准答案或额外回答证据者，不用测试资料或重复文本。保存来源、保留/删除 token 区间、补充来源、证据位置；无法确认有效性标不适用，不按模型得分换题。相同题/长度共享同一 token 序列，N∈{4,8,16} 顺序等分，记录跨块证据。

正式 LongBench 保持完整公开文档，顺序切成最多 7500 tokens 的块并记录实际 N；不筛短样本。正式测试和 Lost in the Middle 不用开发裁剪/补足。Qasper max_new_tokens=128，HotpotQA/MuSiQue=32，官方 F1；600 题完整基线与共用测试子集分别报告。

## 搜索、验证与规则

T、S 分别为 `[0.5,0.7,0.9,1.0]`；默认为 0.9/0.9。按数据集、九格等权平均探索分数，选择全局最佳和每格最佳。平分先取离 0.9/0.9 欧氏距离最近者，再按 T、S 升序。

验证比较默认、探索全局最佳、每格探索最佳，相同实际参数复用生成并保留逻辑方法标签。验证从默认与探索全局最佳选调优固定参数（平分沿用上述确定性顺序）。某格验证得分严格高于固定候选才使用其参数，否则回退固定参数，冻结九格规则。

新输入按 log2(L)、log2(N) 欧氏距离映射最近格，边界夹取、平距取较小 L/N，N 是实际编码块数，原始资料数另记。冻结后用验证集固定10题测 6K/12K，不再调参，随后独立测试。同题/同 L/N 的不可变资料 KV 可在 16 组 T/S 复用，标搜索缓存条件，不能作正式冷启动加速结论。

诊断：每数据集首个有效探索题，4K/4块、16K/16块，默认与探索最佳；层0/15/31，头0/8/16/24，查询末 token 及实际 decode 步骤。重建完整 token 权重并验证对应注意力输出，不能把两个分支权重冒充 token 注意力。性能运行关闭诊断。

## 位置与应用

Lost in the Middle：使用[作者公开20文档数据与评分](https://github.com/nelson-liu/lost-in-the-middle)，在三个版本共同问题集合 seed=42 固定500题；核对问题、答案、文档集合一致，gold 位置0/9/19。max_new_tokens=128，官方 `best_subspan_em`，分位置及整体报告。

Doc2Dial：固定 ID 抽500题，保留全部历史，公开模板及官方评分。三方法为 sequential、ape_fixed、ape_dynamic，各冷一次及同题 GPU KV 热复用一次，热请求必须重新生成。缓存仅覆盖资料及方法前缀，全部对话历史和当前问题在请求侧。记录构建、获取/加载、动态选择、TTFT及总响应，不称磁盘缓存实验。按实际 token 列表、顺序、方法、配置直接比较缓存键，不计算摘要。10/30资料及第二模型只在主实验完成且预算充足时另行考虑，不自动执行。

## 记录、恢复及后台

接口：`scripts/run_campaign.sh start --config campaign.json`、`resume --campaign <id>`、`status --campaign <id>`。启动器脱离终端，单实例锁，记录 PID/工作目录，启动 worker 与本地监控。每题包含任务/样本/组/来源/方法、L/N、块长度、T/S、答案/参考/分数、输出 token 数、缓存、TTFT/总响应、峰值 allocated/reserved、状态及 attempt。TTFT 从请求进入到首 token 可用；总响应包含必要预处理、缓存获取和动态选择，模型加载另记。

逐条 append 并 fsync；恢复按任务/样本/配置跳过成功，保留失败及截断记录，不覆盖答案。配置变更不能冒充同次恢复。系统性 CUDA/接口/模型错误保留现场并停止依赖；样本数据错误留证后继续，不替换。

HTTP HTML 每5秒刷新，展示阶段/方法/配置/状态、完成/计划/失败、预算、分方法/长度速度、ETA、抽样变更、错误与结果入口。启动正常后打开独立浏览器窗口，确认本 campaign 页面加载，再观察速度最多180秒；不足以估计时标明 ETA 暂不可靠，汇报后后台继续，任务保持 RUNNING。监控与 worker 的缓存、临时及浏览器配置均在工作区。

## 80小时调度

首个正式任务启动（含加载）起计连续墙钟80小时；准备、下载及有限正确性短测在此前完成，正式研究不能算准备。初始分配：LongBench12h、探索26h、验证/诊断6h、位置18h、Doc2Dial12h、汇总/故障6h。按已完成正式样本的方法及实际长度分层估计；每阶段及每10分钟更新，不要求 agent 持续轮询。

预计超预算时，按预先固定嵌套 ID 顺序，不参考分数，依序缩量：探索50→35→20→10→6、验证40→30→20→10（144配置和三数据集保留）；共用 LongBench 测试约510→300→150→90；LITM/Doc2Dial500→300→200→100（方法/位置/冷热线配对）。完整600基线保留。每次记录时间依据、前后ID/数量及已产出而未纳入平衡分析的结果。最低规模仍不满足则预算阻塞。80h仅终止本 campaign worker，保存部分结果和未完成清单，不超时或伪报。
